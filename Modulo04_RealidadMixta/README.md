# Módulo IV · Realidad Mixta

**Experiencias que combinan el mundo real y el virtual en Meta Quest**

En este módulo pasamos de la realidad virtual a la **realidad mixta (MR)**: usamos las cámaras de las gafas para ver el entorno real (*passthrough*) y hacemos que el contenido virtual entienda e interactúe con la habitación del jugador.

---

## 🎯 Objetivos

- Activar y configurar el **Passthrough** en un proyecto de Unity.
- Usar la **comprensión de escena** (Scene API) para conocer paredes, suelo, techo y muebles.
- Trabajar con **MR Utility Kit (MRUK)** para colocar contenido en la habitación real.
- Crear y guardar **anclajes espaciales** (*Spatial Anchors*).
- Aplicar oclusión y física sobre el entorno real.
- Usar **Building Blocks** de realidad mixta para acelerar el desarrollo.

---

## 📖 Contenidos

| Apartado | Contenido |
|---|---|
| **Passthrough** | Capa de passthrough, estilos y transiciones VR ↔ MR |
| **Scene / MRUK** | Captura del espacio (*Space Setup*), etiquetas semánticas, colocación de objetos |
| **Spatial Anchors** | Crear, guardar y recuperar anclajes |
| **Interacción con el entorno** | Colisiones con la malla de la habitación, oclusión (*Depth API*) |
| **Proyecto** | Experiencia de realidad mixta |
