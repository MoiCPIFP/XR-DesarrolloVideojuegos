# Módulo V · Multiusuario y optimización

**Experiencias compartidas en red y rendimiento en Meta Quest**

En este módulo aprendemos a crear experiencias en las que varios jugadores comparten el mismo espacio virtual o mixto, y a optimizar nuestras aplicaciones para que funcionen con fluidez en las gafas.

---

## 🎯 Objetivos

### Multiusuario
- Conocer los conceptos básicos de red: host, cliente, sincronización y autoridad.
- Crear una experiencia multijugador con los **Building Blocks** de Meta.
- Sincronizar jugadores, avatares y objetos interactivos.
- Usar **anclajes compartidos** (*Shared Spatial Anchors*) y Colocation para alinear a varios usuarios en la misma habitación.

### Optimización
- Conocer los requisitos de rendimiento de Meta Quest (tasa de fotogramas estable).
- Medir el rendimiento con **Unity Profiler**, **Frame Debugger** y **Meta Quest Developer Hub**.
- Reducir draw calls y polígonos: *batching*, LOD, atlas de texturas, *occlusion culling*.
- Optimizar la iluminación (luces horneadas), los shaders y la configuración del proyecto.
