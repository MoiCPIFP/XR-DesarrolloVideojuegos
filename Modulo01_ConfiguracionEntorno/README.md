# Módulo I · Configuración del entorno

**Primeros pasos: configuración del entorno de desarrollo para Meta Quest**

En este módulo preparamos todo lo necesario para desarrollar con Unity y Meta Quest: la instalación del software, la configuración de las gafas y un primer proyecto que funcione en el dispositivo.

---

## 🎯 Objetivos

- Instalar Unity 6 con el módulo **Android Build Support** (OpenJDK, Android SDK y NDK).
- Activar el **modo desarrollador** en las gafas Meta Quest.
- Instalar **Meta Quest Link** y **Meta Quest Developer Hub**.
- Crear un proyecto de Unity configurado para Meta Quest con **OpenXR** y el **Meta XR SDK**.
- Usar la **Project Setup Tool** para aplicar la configuración recomendada.
- Probar una escena por **Link** y generar la primera **build** en las gafas.

---

## 📖 Contenidos

| Apartado | Contenido |
|---|---|
| **Software necesario** | Unity Hub, Unity 6, módulos Android, Meta Quest Link, Meta Quest Developer Hub |
| **Configuración de las gafas** | Cuenta de desarrollador, modo desarrollador, conexión USB y depuración |
| **Proyecto base** | Plataforma Android (Meta Quest), XR Plug-in Management, OpenXR, compresión ASTC |
| **Meta XR SDK** | Instalación del Meta XR All-in-One SDK desde la Asset Store y el Package Manager |
| **Primera escena VR** | `OVRCameraRig`, prueba con Link y *Build And Run* |
